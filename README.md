# PipesPlus
A mod for NSMBU that enhances the functionality of pipes.

Made for Wii U, powered by [RedCore](https://github.com/Zenith-Team/RedCore) & [Telkin](https://github.com/Zenith-Team/Telkin).
Enjoy :)

## Features
- Connected Pipes: Fixes the "Connected Pipe" option on pipe entrances, allowing you to connect pipes in the same zone together using a path. Make sure to enable the "Face Left" option on the exit pipe's entrance so that it connects backwards to the first pipe.
